# Daily-plan fonts

`NotoEmoji.ttf` is the unmodified variable Noto Emoji font from
https://github.com/google/fonts/blob/main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf,
retrieved on 2026-09-24. See `OFL.txt` for its SIL Open Font License.

`Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf` and
`InterDisplay-SemiBold.ttf` are the unmodified static fonts from
`extras/ttf/` in https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip,
retrieved on 2026-09-25. See `Inter-OFL.txt` for their SIL Open Font License.

The daily-plan renderer embeds subsets of these fonts: Inter for text and
Noto Emoji for monochrome emoji.
