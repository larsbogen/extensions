# Noto Emoji

`NotoEmoji.ttf` is the unmodified variable Noto Emoji font from
https://github.com/google/fonts/blob/main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf,
retrieved on 2026-09-24. See `OFL.txt` for its SIL Open Font License.

The daily-plan renderer embeds a subset for monochrome emoji. Body text uses
Arial installed with macOS; Apple/Microsoft fonts are not redistributed here.
